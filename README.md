# Skills

Reusable Codex skills.

## English Expression Coach

Turn Chinese thoughts and imperfect English attempts into natural, reusable expressions for everyday and workplace communication. The skill preserves your original attempt, explains the key corrections, and keeps a structured learning record. See [SKILL.md](english-expression-coach/SKILL.md) for the full workflow.

### Capabilities

- Recommend natural English first, then explain the important changes.
- Adapt wording for everyday, conversational, or workplace contexts.
- Record the Chinese intent, first attempt, revisions, and next practice focus.
- Generate a responsive visual notebook with before/after comparisons and correction categories.
- Optionally create a recurring review reminder in the user's timezone.

### Installation

Copy `english-expression-coach/` into `$CODEX_HOME/skills/`. If `CODEX_HOME` is unset, use `~/.codex/skills/`.

### Usage

```text
$english-expression-coach
```

Provide the intended Chinese meaning and your English attempt. The skill will correct the expression, explain the key changes, and update the learning notebook when requested.

The skill uses portable workspace-relative paths and contains no personal learning records, screenshots, reminders, or machine-specific settings.

# Skills / 可复用的 Codex Skills

## 英语表达教练

将中文想法和不够自然的英文表达，改写为适用于日常及职场沟通的清晰表达。Skill 会保留你的原始答案、解释关键修改，并维护结构化学习记录。完整流程见 [SKILL.md](english-expression-coach/SKILL.md)。

### 能力

- 先给出自然表达，再解释关键修改。
- 根据日常、口语或职场场景调整措辞。
- 记录中文意图、首次表达、修订历史和下次练习重点。
- 生成包含前后对比和错误类别的响应式可视化笔记。
- 可按用户所在时区创建周期性复习提醒。

### 安装

将 `english-expression-coach/` 复制到 `$CODEX_HOME/skills/`。如果未设置 `CODEX_HOME`，通常使用 `~/.codex/skills/`。

### 使用

```text
$english-expression-coach
```

提供中文意图和你的英文表达。Skill 会完成纠错、解释关键修改，并在需要时更新学习笔记。

该 Skill 使用可移植的工作区相对路径，不包含个人学习记录、截图、提醒或特定电脑配置。
